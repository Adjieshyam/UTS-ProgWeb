# Event Management 2026

## Deskripsi
Aplikasi web untuk melihat informasi event dan melakukan pendaftaran event.

## Teknologi
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Fitur Utama
- Login pengguna
- Dashboard event
- Informasi dan jadwal event
- Form pendaftaran event

## Struktur Proyek
- `frontend/` — antarmuka pengguna
- `backend/` — proses PHP
- `database/` — struktur dan data database
- `laporan/` — dokumentasi proyek UTS
